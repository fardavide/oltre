# Android launcher icon — the master copies

Generated by `art/icon/generate.py`, and **copied** into `androidApp/src/main/res/` — the app
module holds its own `mipmap-*/` and `values/ic_launcher_background.xml`, because a Gradle module
reads resources from its own source set and not from a directory beside the artwork.

So regenerating is two steps: rerun the generator, then copy `mipmap-*/` and
`values/ic_launcher_background.xml` over `androidApp/src/main/res/`. The manifest already points
`android:icon`/`android:roundIcon` at `@mipmap/ic_launcher`.

The foreground is the artwork on transparency; the background is the flat
`#05070D` the artwork was drawn against, so the two recompose exactly.
