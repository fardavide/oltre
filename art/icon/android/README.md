# Android launcher icon — staged

Generated by `art/icon/generate.py`. There is no Android application module yet
(`:client:shell` is an Android *library*), so these are not wired into a build.

When the app module lands, copy `mipmap-*/` and `values/` into its `src/main/res/`
and point `android:icon`/`android:roundIcon` at `@mipmap/ic_launcher`.

The foreground is the artwork on transparency; the background is the flat
`#05070D` the artwork was drawn against, so the two recompose exactly.
